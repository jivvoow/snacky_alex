# 🐶 알렉스의 냠냠캐치 (Snacky Alex!)

강아지 알렉스가 떨어지는 간식을 받아먹는 귀여운 웹게임이에요. PC와 모바일에서 플레이할 수 있어요.

▶ **플레이: https://jivvoow.github.io/snacky_alex/**

## 게임 방법

| 아이템 | 효과 |
| --- | --- |
| 🦴 일반 간식 / ✨ 황금 간식 | +10 / +30점 |
| 🍫 초콜릿, 🐱 토라 | 하트 -1 |
| 🌈 무지개 발바닥 | 8초 피버타임! |

- 조작: PC는 `←` `→`, 모바일은 ◀ ▶ 버튼
- 하트 3개를 모두 잃으면 게임 오버

## 실행

```bash
npm install
npm run dev
```

게임 설정은 `src/config.js`, 이미지와 음악은 `public/assets/`에 있어요.

## 만든 도구

JavaScript · Phaser 3 · Vite
